### Назва: Робота з даними, Google Forms та автоматизація

**Тривалість**: 1.5 години  
**Мета**: Навчити учасників імпортувати дані за допомогою `IMPORTRANGE`, використовувати непрямі посилання (`INDIRECT`), працювати з датами та часом, створювати Google Forms для збору даних і застосовувати базову автоматизацію через Google Apps Script для задач HR (управління даними працівників) і фінансів (облік витрат, звіти).  

**Зміст**:

- **Імпорт даних**:
  - `=IMPORTRANGE()`: Імпорт даних із іншої таблиці.
    - Синтаксис: `=IMPORTRANGE("URL_таблиці", "діапазон")`.
    - Приклад: Імпорт списку працівників із іншої таблиці для створення звіту (HR) або витрат для консолідованого бюджету (фінанси).
    - Налаштування доступу для імпорту.
- **Непрямі посилання**:
  - `=INDIRECT()`: Створення динамічних посилань на дані.
    - Синтаксис: `=INDIRECT(посилання_як_текст)`.
    - Приклад: Вибір даних із певного аркуша залежно від назви (наприклад, витрати за місяцем із аркуша «Січень»).
- **Функції дати та часу**:
  - `=TODAY()`: Поточна дата (приклад: відстеження дедлайнів для HR).
  - `=NOW()`: Поточна дата та час (приклад: позначка часу для звіту).
  - `=DATEDIF()`: Різниця між датами.
    - Синтаксис: `=DATEDIF(початкова_дата, кінцева_дата, одиниця)`.
    - Приклад: Обчислення стажу працівників у роках (HR).
  - `=EOMONTH()`: Кінець місяця.
    - Синтаксис: `=EOMONTH(дата, кількість_місяців)`.
    - Приклад: Планування бюджетів на кінець місяця (фінанси).
- **Google Forms**:
  - Створення Google Form для збору даних.
    - Приклад: Форма для введення витрат (фінанси) або відгуків працівників (HR).
  - Автоматичний імпорт відповідей у Google Sheets.
  - Обробка даних із форм за допомогою формул (наприклад, `SUM` для підрахунку витрат).
- **Google Apps Script**:
  - Вступ до Google Apps Script: створення простого скрипта.
  - Приклади:
    - Скрипт для надсилання email-звіту про витрати (фінанси).
    - Скрипт для очищення даних у таблиці (HR).
  - Використання готових скриптів із бібліотеки.
- **GIF-демонстрація**:
  - Налаштування `IMPORTRANGE` для імпорту даних працівників із іншої таблиці.
  - Використання `INDIRECT` для вибору даних із аркуша за назвою.
  - Створення Google Form для збору витрат і імпорт відповідей у таблицю.
  - Налаштування простого скрипта для надсилання звіту.

- **Практичне завдання**:
  - Створити Google Form для збору даних про витрати (фінанси) або відгуки працівників (HR), імпортувати відповіді в Google Sheets і підрахувати загальну суму за допомогою `SUM`.
  - Використати `IMPORTRANGE` для імпорту даних із іншої таблиці (наприклад, список працівників).
  - Обчислити стаж працівників за допомогою `DATEDIF` (HR) або створити графік платежів із `EOMONTH` (фінанси).

**Технічні рекомендації**:
- GIF-анімації (10–20 секунд) із текстовим поясненням українською, створені через ScreenToGif або Loom.
- Надати шаблони:
  - Google Form для збору витрат (поля: дата, категорія, сума).
  - Таблиця працівників (поля: ID, ім’я, дата прийому).
  - Таблиця витрат із кількома аркушами для `INDIRECT`.
- Використовувати Google Forms для збору виконаних завдань.
- Додати шпаргалку з синтаксисом `IMPORTRANGE`, `INDIRECT`, функцій дати/часу та прикладами скриптів.

**Додаткові поради**:
- **Для HR**: Наголосити на безпеці при використанні `IMPORTRANGE` (обмеження доступу до чутливих даних).
- **Для фінансів**: Підкреслити важливість `EOMONTH` для фінансового планування.
- Додати короткий тест у Google Forms для перевірки засвоєння (`IMPORTRANGE`, `DATEDIF`, Google Forms).
- Пояснити, як перевіряти правильність імпортованих даних, щоб уникнути помилок.

**Приклади для практики**:
- **HR**: Створити Google Form для збору відгуків працівників (поля: ім’я, департамент, коментар), імпортувати відповіді в Google Sheets. Використати `IMPORTRANGE` для імпорту списку працівників із іншої таблиці. Обчислити стаж працівників за допомогою `DATEDIF`.
- **Фінанси**: Створити Google Form для введення витрат (дата, категорія, сума), імпортувати дані в таблицю. Використати `INDIRECT` для вибору витрат із аркуша за назвою (наприклад, «Січень»). Створити графік платежів із `EOMONTH`.
