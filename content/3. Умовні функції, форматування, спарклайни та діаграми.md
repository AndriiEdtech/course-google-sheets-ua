### Назва: Умовні функції, форматування, спарклайни та діаграми

**Тривалість**: 1.5 години  
**Мета**: Навчити учасників використовувати умовні функції (`SUMIF`, `SUMIFS`, `AVERAGEIF`, `AVERAGEIFS`, `ABS`, `ROUND`), умовне форматування, спарклайни та діаграми для аналізу та візуалізації даних у задачах HR (аналіз продуктивності працівників) і фінансів (облік витрат, звіти).  

**Зміст**:

- **Умовні функції**:
  - `=SUMIF()`: Сума за однією умовою.
    - Синтаксис: `=SUMIF(діапазон_критерію, критерій, [діапазон_сумування])`.
    - Приклад: Сума витрат за категорією «Маркетинг» (фінанси).
  - `=SUMIFS()`: Сума за кількома умовами.
    - Синтаксис: `=SUMIFS(діапазон_сумування, діапазон_критерію1, критерій1, [діапазон_критерію2, критерій2, ...])`.
    - Приклад: Сума витрат за категорією «Логістика» за січень (фінанси).
  - `=AVERAGEIF()`: Середнє за однією умовою.
    - Синтаксис: `=AVERAGEIF(діапазон_критерію, критерій, [діапазон_усереднення])`.
    - Приклад: Середня зарплата в департаменті «IT» (HR).
  - `=AVERAGEIFS()`: Середнє за кількома умовами.
    - Синтаксис: `=AVERAGEIFS(діапазон_усереднення, діапазон_критерію1, критерій1, [діапазон_критерію2, критерій2, ...])`.
    - Приклад: Середня продуктивність працівників за період і департамент (HR).
  - `=ABS()`: Абсолютне значення.
    - Синтаксис: `=ABS(число)`.
    - Приклад: Різниця між плановими та фактичними витратами (фінанси).
  - `=ROUND()`: Округлення чисел.
    - Синтаксис: `=ROUND(число, кількість_знаків)`.
    - Приклад: Округлення зарплат до двох знаків після коми (HR).
- **Умовне форматування**:
  - Градієнтне форматування: Колірна шкала для візуалізації даних.
    - Приклад: Виділення витрат від низьких (зелений) до високих (червоний).
  - Правила на основі умов: Виділення значень за критеріями.
    - Приклад: Позначення працівників із продуктивністю нижче 80% червоним кольором.
  - Використання формул у форматуванні.
    - Приклад: Виділення витрат, що перевищують бюджет.
- **Спарклайни**:
  - Створення спарклайнів для відображення трендів у клітинці.
    - Типи: лінійний, стовпчиковий.
    - Приклад: Тренд витрат за місяцями (фінанси) або продуктивності працівників (HR).
  - Налаштування: кольори, масштаб.
- **Діаграми**:
  - Типи діаграм: гістограма, кругова діаграма, лінійний графік.
  - Налаштування: підписи, легенди, кольори.
  - Приклади:
    - HR: Кругова діаграма для розподілу працівників за департаментами.
    - Фінанси: Гістограма для порівняння планових і фактичних витрат.
- **GIF-демонстрація**:
  - Налаштування `SUMIFS` для підрахунку витрат за категорією та місяцем.
  - Застосування градієнтного форматування до стовпця витрат.
  - Створення спарклайну для тренду витрат.
  - Побудова кругової діаграми для розподілу витрат за категоріями.

- **Практичне завдання**:
  - Створити таблицю витрат (фінанси) із `SUMIFS` для підрахунку за категоріями та місяцями, застосувати градієнтне форматування та додати спарклайни для трендів.
  - Створити таблицю продуктивності працівників (HR) із `AVERAGEIF`, умовним форматуванням для низької продуктивності та круговою діаграмою для розподілу за департаментами.

**Технічні рекомендації**:
- GIF-анімації (10–20 секунд) із текстовим поясненням українською, створені через ScreenToGif або Loom.
- Надати шаблони таблиць:
  - Таблиця витрат: дата, категорія, сума, плановий бюджет.
  - Таблиця працівників: ID, ім’я, департамент, продуктивність (%).
- Використовувати Google Forms для збору виконаних завдань.
- Додати шпаргалку з синтаксисом `SUMIF`, `SUMIFS`, `AVERAGEIF`, `AVERAGEIFS`, а також прикладами умовного форматування.

**Додаткові поради**:
- **Для HR**: Наголосити на використанні умовного форматування для швидкого виявлення проблем (наприклад, низька продуктивність або відсутність на роботі).
- **Для фінансів**: Підкреслити важливість діаграм для презентації звітів керівництву.
- Додати короткий тест у Google Forms для перевірки засвоєння (`SUMIFS`, умовне форматування, діаграми).

**Приклади для практики**:
- **HR**: У таблиці з даними працівників (ID, ім’я, департамент, продуктивність) порахувати середню продуктивність у департаменті «Маркетинг» за допомогою `AVERAGEIF`. Застосувати умовне форматування для виділення продуктивності нижче 80%. Створити кругову діаграму для розподілу працівників за департаментами.
- **Фінанси**: У таблиці витрат (дата, категорія, сума) порахувати суму витрат за категорією «Логістика» за січень за допомогою `SUMIFS`. Застосувати градієнтне форматування для стовпця сум. Додати спарклайни для тренду витрат за місяцями та гістограму для порівняння витрат за категоріями.
