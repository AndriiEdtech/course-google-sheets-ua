
**Тривалість**: 1 година  
**Мета**: Ознайомити учасників з інтерфейсом Google Sheets, базовими функціями розрахунків та інструментами фільтрації/сортування для ефективної роботи HR та фінансистів.  

**Зміст**:

- **Огляд Google Sheets**:
  - Інтерфейс: аркуші, рядки, стовпці, панель інструментів.
  - Відмінності від Excel: хмарність, спільна робота, обмеження.
  - Приклад: створення нової таблиці для HR (список працівників) або фінансів (трекер витрат).
- **Базові функції розрахунків**:
  - `=SUM()`: Сума чисел (приклад: загальна зарплата працівників).
  - `=PRODUCT()`: Множення чисел (приклад: загальна вартість товарів за кількістю × ціна).
  - `=SUMPRODUCT()`: Сума добутків (приклад: множення кількості одиниць на ціну для кількох позицій).
  - `=AVERAGE()`: Середнє значення (приклад: середня продуктивність працівників за місяць).
- **Фільтри та сортування**:
  - Налаштування фільтрів для вибірки даних (приклад: відображення витрат за певною категорією).
  - Створення представлень фільтрів (Filter Views) для роботи кількох користувачів.
  - Сортування даних за одним або кількома критеріями (приклад: сортування працівників за датою прийому).
- **GIF-демонстрація**:
  - Створення таблиці витрат із застосуванням `SUM` для підсумків і фільтру для вибірки даних за місяцем.
  - Сортування списку працівників за алфавітом або вислугою.
- **YouTube-відео**:
  - [Google Таблиці для початківців](https://www.youtube.com/watch?v=9wX9zHNZP2o) (укр, ~4 хв) – базовий огляд інтерфейсу та фільтрів.
  - [How to Use Filters in Google Sheets](https://www.youtube.com/watch?v=0M7l4M8q1fU) (англ, ~3 хв) – пояснення фільтрів із субтитрами.
- **Практичне завдання**:
  - Створити таблицю для підрахунку місячних витрат (фінанси) або списку працівників (HR) із застосуванням `SUM`, `AVERAGE` та фільтру за категорією/департаментом.

**Технічні рекомендації**:
- GIF-анімація (10–20 секунд) із текстовим поясненням українською, створена через ScreenToGif або Loom.
- Надати шаблон таблиці (наприклад, трекер витрат або список працівників) для практики.
- Використовувати Google Forms для збору виконаних завдань.

**Додаткові поради**:
- Для HR: підкреслити важливість чіткої структури даних (наприклад, унікальні ID працівників).
- Для фінансів: наголосити на форматуванні чисел (грошовий формат, два знаки після коми).
- Додати короткий тест у Google Forms для перевірки засвоєння (`SUM`, фільтри).
